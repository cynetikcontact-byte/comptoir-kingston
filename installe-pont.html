🔌 Installe-Pont KINGTOOLS

Configurer un nouveau Raspberry pour une boutique — sans SSH, sans commande

⚠️ Ouvre cette page avec Google Chrome ou Microsoft Edge.
1 Le code de la boutique

Recopie le code d'installation affiché dans KINGTOOLS → Ponts TPE, à côté de la boutique.

2 Le Wi-Fi de la boutique

Le réseau Wi-Fi de la boutique (pas le tien), tel qu'écrit sur la box.

3 Brancher la clé du Raspberry

Branche la clé USB du nouveau Raspberry sur cet ordinateur (si le Mac dit « disque illisible » → Ignorer, jamais Initialiser). Puis :

✓

Clé configurée

⚠️ ÉJECTE LA CLÉ PROPREMENT AVANT DE LA RETIRER

Clic droit sur l'icône « bootfs » → Éjecter (Windows : icône USB → Éjecter). Attends que l'icône disparaisse, puis débranche.
  1. Mets la clé dans le Raspberry, branche l'alimentation.
  2. Patiente 3 à 4 min : il rejoint le Wi-Fi, contacte le serveur et s'appaire tout seul.
  3. Branche le TPE sur le même réseau.
  4. Vérifie dans KINGTOOLS → Ponts TPE : la boutique passe EN LIGNE. Fais un paiement test de 1 €.
